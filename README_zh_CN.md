# 更多 TNT（More TNT）

[English README](README.md)

“更多 TNT”是一个适用于 Minecraft 26.2 的 Fabric 模组，加入 32 种明确分工的 TNT。它面向实际工程用途：一键伐木、挖隧道、拆除时保护矿物、排水、改造环境；当然，也包含真正用于大规模爆破的高威力型号。

## 前置与安装

- Minecraft `26.2`
- Fabric Loader `0.19.3` 或更高版本
- Fabric API `0.157.0+26.2` 或兼容的更高版本
- Java `25`

将 `moretnt-1.3.7+26.2.jar` 和 Fabric API 一同放进当前实例的 `mods` 文件夹，然后启动游戏。创造模式物品栏会新增 **更多 TNT** 页签，包含全部变种和萤石照明箭；生存模式下，全部配方都可在普通工作台中完成。

## 工作方式

- 用打火石、火焰弹或红石信号点燃任意 TNT。
- 每种 TNT 均有原创 64×64 侧面、顶部和底部材质。侧面使用高对比度用途代码（如 `STN`、`ORE`、`H2O`、`NUC`、`SNU`），顶部配套用途图标；每个物品模型都指向自己的方块模型，因此创造物品栏/JEI 缩略图与实际方块材质一致。
- 点燃后方块会变成真正的已点燃 TNT 实体，拥有原版式的 4 秒（80 游戏刻）引信、重力、弹跳、烟雾、膨胀和闪烁动画。
- 已支持原版 TNT 的主要点火入口：红石、打火石、火焰弹、发射器使用上述点火物品、燃烧的投射物、相邻火焰、相邻岩浆以及爆炸连锁。选择性/环境 TNT 会在效果范围内把原版 TNT 与更多 TNT 以随机短引信的实体形式点燃，不再中断连锁。通过命令设置 `unstable=true` 的 TNT 也支持原版“不稳定方块被破坏”触发方式。
- **萤石照明弹**是唯一不以手持放置方式使用的 TNT：右键会投出带实体物理、30 游戏刻引信的 TNT，保留重力与碰撞；只有爆炸范围内存在可命中的生物时，才会造成威力 3 的实体伤害与击退效果，且不会破坏任何方块；没有生物时只放置 1 个萤石。通过命令放置的萤石照明弹方块仍可使用上列全部原版点火方式。
- **萤石照明箭**可被弓、弩和发射器当作普通箭使用，水下同样有效；命中方块时会在命中面外侧生成 1 个萤石（需要时替换水源）并爆发光粒子，命中生物时会附加 10 秒原版发光效果并爆发同样的光粒子。
- 选择性 TNT 默认跳过带方块实体的方块，例如箱子和机器。“护矿 TNT”“拆除 TNT”“清空 TNT”还会识别大多数注册名遵循 `*_ore` 等常见规范的模组矿石。
- 模组遵守 `doTNTExplodes` 游戏规则。该规则关闭时，更多 TNT 无法被点燃，也不会产生连锁爆破。
- 定向采掘 TNT 会按普通方式掉落方块；**清空 TNT** 会刻意不掉落物品；基岩 TNT 只会移除基岩，绝不会掉落基岩。

| 护矿 TNT | 金苹果 | 拆除非矿物方块，同时保留矿石。 |
| 收获 TNT | 钻石锄 | 收割农作物、花、藤蔓、甘蔗和仙人掌。 |
| 玻璃 TNT | 玻璃 | 仅拆除玻璃方块和玻璃板。 |
| 羊毛 TNT | 剪刀 | 仅拆除羊毛、地毯和床。 |
| 混凝土 TNT | 混凝土 | 仅清除混凝土、混凝土粉末和陶瓦。 |

| 木材 TNT | 橡木原木 | 拆除木制建筑方块，不影响矿石。 |

| 灌岩浆 TNT | 岩浆桶 | 在附近空气格生成岩浆。 |
| 冻结 TNT | 蓝冰 | 将附近水源变成冰。 |

| 萤石照明箭 | 1 个萤石照明弹 + 1 支箭 | 无序合成一次得到 **10** 支；获得两种材料后会解锁配方书。水下命中方块也能生成萤石，命中生物会获得 10 秒发光。 |
| 排水 TNT | 海绵 | 清除附近的水和岩浆。 |
| 隧道开凿弹 | 铁轨 | 识别并清除可破坏、无方块实体的地形，开凿南北向 3 × 3 隧道。 |
| 竖井开凿弹 | 脚手架 | 识别并清除可破坏、无方块实体的地形，开凿 3 × 3 垂直竖井。 |
| 采石场 TNT | 钻石 | 开采石材与矿石，同时保留容器。 |
| 地表平整弹 | 草方块 | 清除横向范围内从爆炸 Y 高度起的普通方块；原版 TNT 炸不掉的高爆炸抗性方块会保留。 |
| 壕沟 TNT | 石砖 | 开凿东西向的宽壕沟。 |
| 拆除 TNT | 黑曜石 | 通用拆除，并保护矿石及容器。 |
| 巨爆 TNT | 下界之星 | 半径 16 的常规大爆炸。 |

## 使用注意事项

1. 使用巨型爆破弹、超巨爆破弹、核爆弹、超级核爆弹或基岩消解弹前，务必备份存档；它们造成的地形变化不可恢复。两种核爆弹处理大范围爆炸时也可能导致明显卡顿。
2. 建议先在存档副本测试。选择性 TNT 依赖方块标签和注册名判断目标，重度整合包中的特殊方块可能与原版表现不同。
3. 注水、灌岩浆、燃烧、照明、冻结与排水 TNT 主要改变环境，并不是普通方块爆炸。萤石照明弹为投掷式 TNT：仅在爆炸范围存在生物时，它才会伤害和击退实体；没有生物时只进行照明，且永远不会破坏方块。每支萤石照明箭命中方块后都会留下 1 个永久萤石；请勿在农田、红石装置或木制建筑旁随意使用。
4. 隧道 TNT 固定沿南北方向挖掘，壕沟 TNT 固定沿东西方向挖掘；放置前请确认方向。
5. 容器保护只针对带方块实体的方块。高威力 TNT 不是备份的替代品。

## 探索战利品

萤石照明箭也会自然生成在原版战利品宝箱中：地牢（45%）、废弃矿井（35%）、要塞走廊（35%）、沉船补给箱（30%）、大型海底遗迹（30%）、制箭师房屋（20%）和埋藏的宝藏（20%）。每次成功生成会获得一小捆 4–24 支箭，具体数量取决于宝箱类型。

## 材质来源

`docs/texture-concept-reference.png` 是用于确定方向的 AI 视觉参考图。游戏内实际使用的材质位于 `src/main/resources/assets/moretnt/textures/block/`，均为原创、程序化生成的 64×64 PNG 像素画；萤石照明箭另有原创 32×32 原版风格物品与实体贴图。可用 `tools/GenerateTntTextures.java` 和 `tools/GenerateGlowstoneArrowTextures.java` 重现生成过程。

## 开发与构建

本项目使用 Gradle、Fabric Loom 和 Java 25。可在项目目录中执行：

```powershell
./gradlew build
```

重映射后的成品 jar 将输出到 `build/libs/`。
