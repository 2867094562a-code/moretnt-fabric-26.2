# 更多 TNT（More TNT）

[English README](README.md)

“更多 TNT”是一个适用于 Minecraft 26.2 的 Fabric 模组，加入 30 种明确分工的 TNT。它面向实际工程用途：一键伐木、挖隧道、拆除时保护矿物、排水、改造环境；当然，也包含真正用于大规模爆破的高威力型号。

## 前置与安装

- Minecraft `26.2`
- Fabric Loader `0.19.3` 或更高版本
- Fabric API `0.157.0+26.2` 或兼容的更高版本
- Java `25`

将 `moretnt-1.1.0+26.2.jar` 和 Fabric API 一同放进当前实例的 `mods` 文件夹，然后启动游戏。创造模式物品栏会新增 **更多 TNT** 页签，包含全部变种；生存模式下，全部配方都可在普通工作台中完成。

## 工作方式

- 用打火石、火焰弹或红石信号点燃任意 TNT。
- 每种 TNT 均有原创 32×32 侧面、顶部和底部材质。侧面使用高对比度用途代码（如 `STN`、`ORE`、`H2O`、`BDR`），顶部配套用途图标；方块名与物品栏名称均已分别汉化/英文化。
- 点燃后方块会变成真正的已点燃 TNT 实体，拥有原版式的 4 秒（80 游戏刻）引信、重力、弹跳、烟雾、膨胀和闪烁动画。
- 已支持原版 TNT 的主要点火入口：红石、打火石、火焰弹、发射器使用上述点火物品、燃烧的投射物、相邻火焰、相邻岩浆以及爆炸连锁。选择性/环境 TNT 会在效果范围内把原版 TNT 与更多 TNT 以随机短引信的实体形式点燃，不再中断连锁。通过命令设置 `unstable=true` 的 TNT 也支持原版“不稳定方块被破坏”触发方式。
- 选择性 TNT 默认跳过带方块实体的方块，例如箱子和机器。“护矿 TNT”“拆除 TNT”“清空 TNT”还会识别大多数注册名遵循 `*_ore` 等常见规范的模组矿石。
- 模组遵守 `doTNTExplodes` 游戏规则。该规则关闭时，更多 TNT 无法被点燃，也不会产生连锁爆破。
- 定向采掘 TNT 会按普通方式掉落方块；**清空 TNT** 会刻意不掉落物品；基岩 TNT 只会移除基岩，绝不会掉落基岩。

全部配方均为无序合成：在任意工作台格子中放入一枚原版 TNT 和下表材料即可。

| TNT | 额外材料 | 功能 |

| 伐木 TNT | 钻石斧 | 仅清除原木、木头、竹子和树叶。 |
| 土方 TNT | 钻石锹 | 仅清除泥土、沙子、砂砾、黏土和泥巴。 |
| 采石 TNT | 钻石镐 | 清除常见石头、深板岩、凝灰岩、方解石等岩石。 |
| 矿脉 TNT | 绿宝石 | 仅开采矿石，包含大多数模组矿石。 |
| 护矿 TNT | 金苹果 | 拆除非矿物方块，同时保留矿石。 |
| 收获 TNT | 钻石锄 | 收割农作物、花、藤蔓、甘蔗和仙人掌。 |
| 玻璃 TNT | 玻璃 | 仅拆除玻璃方块和玻璃板。 |
| 羊毛 TNT | 剪刀 | 仅拆除羊毛、地毯和床。 |
| 混凝土 TNT | 混凝土 | 仅清除混凝土、混凝土粉末和陶瓦。 |
| 碎冰 TNT | 浮冰 | 仅清除冰与雪。 |
| 下界采掘 TNT | 下界岩 | 清除下界岩、玄武岩、黑石和灵魂土。 |
| 末地采掘 TNT | 末地石 | 清除末地石和紫珀方块。 |
| 木材 TNT | 橡木原木 | 拆除木制建筑方块，不影响矿石。 |
| 注水 TNT | 水桶 | 在附近空气格生成水源。 |
| 灌岩浆 TNT | 岩浆桶 | 在附近空气格生成岩浆。 |
| 冻结 TNT | 蓝冰 | 将附近水源变成冰。 |
| 燃烧 TNT | 火焰弹 | 点燃附近安全的空气格。 |
| 照明 TNT | 萤石 | 在附近空气格放置萤石。 |
| 排水 TNT | 海绵 | 清除附近的水和岩浆。 |
| 隧道 TNT | 铁轨 | 开凿南北向 3 × 3 隧道。 |
| 竖井 TNT | 脚手架 | 开凿 3 × 3 垂直竖井。 |
| 采石场 TNT | 钻石 | 开采石材与矿石，同时保留容器。 |
| 平整 TNT | 草方块 | 清除爆点同高度附近的土方。 |
| 壕沟 TNT | 石砖 | 开凿东西向的宽壕沟。 |
| 拆除 TNT | 黑曜石 | 通用拆除，并保护矿石及容器。 |
| 巨爆 TNT | 下界之星 | 半径 16 的常规大爆炸。 |
| 超巨爆 TNT | 龙蛋 | 半径 32 的超大爆炸。 |
| 黑曜石 TNT | 哭泣的黑曜石 | 拆除黑曜石、哭泣的黑曜石和重生锚。 |
| 基岩 TNT | 下界合金锭 | 移除半径 4 内的基岩，且不会掉落基岩。 |
| 清空 TNT | 末影珍珠 | 无掉落地清除方块，保护矿石和容器。 |

## 使用注意事项

1. 使用巨爆 TNT、超巨爆 TNT 或基岩 TNT 前，务必备份存档；它们造成的地形变化不可恢复。
2. 建议先在存档副本测试。选择性 TNT 依赖方块标签和注册名判断目标，重度整合包中的特殊方块可能与原版表现不同。
3. 注水、灌岩浆、燃烧、照明、冻结与排水 TNT 主要改变环境，并不是普通爆炸。请勿在农田、红石装置或木制建筑旁随意使用。
4. 隧道 TNT 固定沿南北方向挖掘，壕沟 TNT 固定沿东西方向挖掘；放置前请确认方向。
5. 容器保护只针对带方块实体的方块。高威力 TNT 不是备份的替代品。

## 材质来源

`docs/texture-concept-reference.png` 是用于确定方向的 AI 视觉参考图。游戏内实际使用的材质位于 `src/main/resources/assets/moretnt/textures/block/`，均为原创、程序化生成的 32×32 PNG 像素画；可用 `tools/GenerateTntTextures.java` 重现生成过程。

## 开发与构建

本项目使用 Gradle、Fabric Loom 和 Java 25。可在项目目录中执行：

```powershell
./gradlew build
```

重映射后的成品 jar 将输出到 `build/libs/`。
